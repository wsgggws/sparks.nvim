# sparks.nvim 0.2.0

This release makes the original typing experience dependable: Toggle now stops all
feedback, combos restart after inactivity, adaptive overlays follow real editor windows,
bottom positions are correct, and CJK/emoji rendering uses display widths and byte offsets
correctly. Sound is off by default and external players are launched without shell string
construction. Tests, CI, health checks, and `:help sparks` establish the maintenance base.
