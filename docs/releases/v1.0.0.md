# sparks.nvim 1.0.0

Version 1.0 freezes the documented setup, emission, registration, and command interfaces.
Neovim 0.10 is the minimum supported version; stable and nightly builds are covered in CI.
The release includes a public-interface benchmark, reproducible demo asset, full English
and Chinese documentation, a changelog, and contribution guidance for community presets.
Cursor overlays keep empty cells fully transparent and particle cells opaque. Inserted text
is hidden by default, Combo placement is configurable, and a small particle-free area keeps
the active cursor row readable; corner mode retains its previous opacity and text behavior.
The cursor-mode visual center is configurable and defaults to two columns right and one row
below the cursor, while the protected area remains anchored to the actual cursor position.
Placement is selected with one `position` option and defaults to `right-center`; set it to
`top-right`, `bottom-right`, or `cursor` for the other supported layouts.
